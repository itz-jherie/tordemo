# TORSTUDIO — Client Concept Showroom
Motion-first portfolio concepts. Greyscale, Instrument Sans, logo at `public/torstudio.png`.
Routes: `/` showroom · `/concept-kinetic` 01 Kinetic Editorial · `/concept-noir` 02 Noir Gallery · `/concept-playground` 03 Poster Playground · `/concept-signal` 04 Broadcast OS.
Run: `npm install` then `npm run dev`, open http://localhost:3000. Show the client all four, ask for one feeling, expand the winner into the full site.
